# Ember i3 dotfiles

Личные Linux dotfiles для **десктопа на i3 и X11**.

Это не приложение и не библиотека — это **готовая конфигурация рабочего окружения**: оконный менеджер, бар, терминал, shell, tmux, лаунчер, композитор и набор вспомогательных скриптов, разложенных в Stow-friendly структуре.

## Что это за репозиторий

Репозиторий настраивает полноценное рабочее окружение на базе:
- **i3** — тайлинговый WM
- **polybar** — статус-бар
- **picom** — композитор
- **rofi** — лаунчер и меню
- **alacritty** — терминал
- **tmux** — мультиплексор терминала
- **zsh** с Oh My Zsh + Powerlevel10k

Тема/стиль:
- кастомная палитра **Ember** — тёплый графитово-янтарный стиль для i3, polybar, tmux и терминала

Дополнительно есть:
- **OSD popups** для громкости и яркости
- скрипт блокировки экрана
- скрипты скриншотов
- ротация обоев из папки с обоями, хранящейся в этом репозитории
- переключение лимита заряда батареи
- переключение reading mode
- пользовательские `systemd`-юниты

## Структура репозитория

Каждая директория верхнего уровня повторяет путь относительно `$HOME`.

Примеры:
- `i3/.config/i3/config` → `~/.config/i3/config`
- `tmux/.config/tmux/tmux.conf` → `~/.config/tmux/tmux.conf`
- `scripts/.config/scripts/...` → `~/.config/scripts/...`

Поэтому репозиторий совместим с [GNU Stow](https://www.gnu.org/software/stow/).

## Что внутри

- `i3` — конфиг i3
- `polybar` — конфиг бара и вспомогательные скрипты
- `picom` — конфиг композитора
- `rofi` — конфиг лаунчера
- `dunst` — конфиг демона уведомлений, оформлен в стиле палитры Ember
- `alacritty` — конфиг терминала
- `tmux` — конфиг tmux и TPM-плагины
- `zshrc` — конфиг shell
- `systemd` — пользовательские сервисы
- `scripts` — утилитарные скрипты
- `wallpapers` — коллекция обоев, синхронизируемая в `~/.local/share/wallpapers`
- `claude` — настройки Claude Code (в т.ч. хук уведомлений на рабочий стол через dunst)
- `gtk` — тёмная тема GTK3/GTK4 (Adapta-Nokto)

## Установка

Клонировать с submodules:

```sh
git clone --recurse-submodules <repo-url>
cd my-i3-dotfiles
```

Разложить через GNU Stow:

```sh
stow alacritty claude dunst gtk i3 picom polybar rofi scripts systemd tmux wallpapers zshrc
```

Либо разложить/засимлинковать файлы вручную.

## Что требуется

Базовые компоненты этого окружения:
- i3
- polybar
- picom
- rofi
- alacritty
- tmux
- zsh
- Oh My Zsh
- Powerlevel10k

Для части вспомогательных функций также нужны утилиты вроде:
- `brightnessctl`
- `wpctl` / `pactl`
- `dunst` / `dunstify`
- `xss-lock`
- `greenclip`
- `xrandr`
- `xclip` или `wl-copy`

## Обои

Теперь обои лежат прямо в репозитории, в:
- `wallpapers/.local/share/wallpapers`

Скрипт ротации обоев читает:
- обои из репозитория по умолчанию
- либо `$WALLPAPER_DIR`, если нужно переопределить путь

## Примечания

- Целевая сессия: **X11 + i3**
- Конфиг заточен под машину и привычки автора, но хорошо подходит как база
- Если хочешь адаптировать отдельные части, смотри файлы внутри соответствующих пакетов
